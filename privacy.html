Privacy notice

BookTime Studio is an owner-operated private tool. Contact: booktimestories.studio@gmail.com.

Google data and purpose

With owner consent, the tool uses YouTube readonly access to identify the connected channel and inspect authorized video information. YouTube upload access is used for owner-authorized uploads. OAuth access and refresh tokens are retained to support authorized operations. The current integration does not request Gmail, Drive or YouTube Analytics API access.

Storage and sharing

Credentials are stored in restricted files on the owner's VPS. Episode manifests, status records, media and approvals are stored separately. Protected backups on that VPS may contain credentials and channel data. An off-server backup destination is not configured. Only the owner and explicitly authorized administrators should have access.

The tool communicates with Google to authenticate and perform authorized YouTube operations. Google user data is not sold or used for advertising profiles. Current narration and rendering run locally; Google channel data is not sent to an external generative model service.

Retention and removal

Data is retained while the owner operates the tool; automated backup retention deletion is not configured. Access can be revoked through Google Account third-party connections. Revocation stops future authorized access but does not automatically erase local files or backups. Contact the operator to remove stored credentials, related records and backup copies. Removing local data does not delete an uploaded YouTube video; deletion on YouTube requires a separate action.

Limited use

BookTime Studio's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. This notice must be reviewed before changing scopes, processors, sharing or retention practices.
